# WorkWise AI - AI Productivity Assistant

## Project Overview
WorkWise AI is an AI-powered workplace assistant designed to improve productivity. This bot helps professionals with daily tasks.

## Features
1.  **Email Generator:** Creates professional workplace emails (formal, apology, follow-up)
2.  **Meeting Summarizer:** Summarizes long meeting transcripts into key points and action items
3.  **Task Planner:** Breaks down complex tasks into manageable to-do lists with priorities
